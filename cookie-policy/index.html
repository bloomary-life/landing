Cookie Policy

Last updated: October 8, 2026

This Cookie Policy explains how Bloomary uses cookies, browser storage, and similar technologies on https://bloomary.life/ and https://platform.bloomary.life/.

Bloomary does not use advertising cookies, retargeting pixels, or cross-site tracking.

Essential Storage

Bloomary uses local browser storage and session storage to provide core product features, including drafts, editor state, LinkedIn authorization state, and user-provided Gemini API key storage for the browser session. This storage is necessary for the service to work.

When you choose Essential only on the Cookie Policy banner, Bloomary stores that choice in local browser storage so the banner does not appear on every visit.

Web LinkedIn login also uses an essential Secure, httpOnly session cookie on the API host. It contains a random session identifier, and browser JavaScript cannot read it. The session ends on disconnect, token expiry, or backend restart.

Analytics

Bloomary does not currently load website analytics.

Third-Party Services

Third-party services such as LinkedIn, Telegram, payment providers, Apple, Google, and Cloudflare may use their own cookies or similar technologies when you interact with their services, open their pages, authorize LinkedIn, join the community, pay, or use AI assistance. Their own policies apply to those services.

The support form on bloomary.life uses Google reCAPTCHA to block spam. The reCAPTCHA script loads only after you start using the form, and Google may set its own cookies and process device and browser data under Google's privacy policy.

Managing Storage

You can clear Bloomary local data by clearing site data for bloomary.life and platform.bloomary.life in your browser, closing the browser session, using in-app deletion controls, or removing the app from your device.
